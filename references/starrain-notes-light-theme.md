# 星雨笔录日间报告主题

所有本 Skill 生成的 HTML 报告必须使用本主题。它把报告的发布者品牌和被分析项目的产品名称分开：品牌固定，项目名称始终取自证据。

## 固定身份

- 固定中文品牌：`星雨笔录 · 软件工程全景报告`
- 固定英文眉题：`STAR RAIN NOTES · ENGINEERING REPORT`
- 页面 `<title>`：`{项目名称}｜星雨笔录软件工程全景报告`
- 头图区第一行必须是英文眉题，主标题必须以 `{项目名称}` 开头；不得把 `星雨笔录` 误写成被分析项目的产品名。

## 阅读与信息层级

- 日间底色使用冷白 `#f5f8fc`，正文纸面 `#fff`，墨色 `#15233b`，主蓝 `#2766d8`；不得改成深色主题或棕褐色主题。
- 宽屏采用「260px 粘性目录 + 最多 1050px 正文」；小于 900px 时目录回到正文上方。
- 使用圆角白色章节卡片、轻阴影、蓝色二级标题下划线、浅蓝表头、斑马纹表格、等宽代码底纹。正文 15px / 1.75，中文字体依次为 `Microsoft YaHei`、`PingFang SC`、Arial。
- 目录、表格、筛选、`details`、SVG 图表必须保持键盘可用、窄屏可读和离线可用。不要使用 CDN、网络字体、外链脚本或运行时数据请求。

## PDF 唯一导出路径

- 每个 HTML（总册与所有分册）都要有固定右下角按钮：`<button id="export-pdf" type="button">导出 PDF</button>`。不提供 DOCX、Markdown、图片、HTML 下载或其他导出按钮。
- 按钮调用原生 `window.print()`，让用户在浏览器打印面板选择“另存为 PDF”。这是静态离线 HTML 中兼容 Chrome、Edge 与系统打印设置的可靠 PDF 路径；页面不得伪称可以无浏览器权限静默写入 PDF 文件。
- 打印前展开正文区域的折叠项；打印结束后还原原有展开状态。打印样式必须隐藏搜索框、交互按钮和浮动导出按钮；目录转为第一页，正文单栏、白底、无卡片阴影；链接以普通文本颜色打印。
- 纸张设置为 A4，页边距 12mm；表格允许横向滚动的屏幕样式不能带到打印样式。大型图表可横向分页，但不能裁掉内容。

## 可复用基线

以 [`templates/starrain-notes-light.html`](../templates/starrain-notes-light.html) 为唯一模板基线：复制其 CSS、目录结构、PDF 按钮和脚本，再填入已核验的项目内容。不要从旧报告复制另一套 CSS。
